How the score is counted
  • Only tasks whose reference solution passes its own tests are scored. The others are listed as Not scored, with the reason.
  • Each task has one result that counts. Tasks that ran out of time on their first attempt were run once more on the PC with 3× their agent time, and that later result counts.
  • Most tasks ran on Daytona Tier 1 sandboxes. Tasks that need 8 GiB of memory, or a host the Tier 1 network blocks, ran on a WSL2 PC with local Docker.
  • Trials stopped because the DeepSeek account ran out of credit don't count as attempts.
  • merge-diff-arc-agi-task and regex-log failed because of the harness: the 180 s command limit cut off an apt-get install, which then broke the test's own install.
