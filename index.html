Minimal Terminal Agent

A minimalist terminal agent.

A succinct core for agentic research.

View on GitHub Read the design
$ git clone https://github.com/Eric2i/minimal-terminal-agent && cd minimal-terminal-agent && uv sync

Designed for research

MTA keeps the core minimal so that every behaviour is easy to trace, change and study. Planning, memory and context management are built on top, not baked in.

Inference Engine Agnostic

Works with any OpenAI-compatible chat-completions endpoint: vLLM, SGLang, Ollama or a hosted API. Point MTA_BASE_URL at it and go.

Native Sandbox Environment

Every episode runs in a fresh Docker container that is removed afterwards, so each run starts from the same image and leaves nothing behind.

Token-level Replay

Each episode is one serializable trajectory: SFT-ready messages, plus per-step slots for token IDs, logprobs and loss masks.

How it works

The model sends a tool call, the sandbox returns what happened, and the loop repeats until the model calls submit. Below is a replay of a real run, step by step; every step is recorded in the trajectory.

    Quick start
    
    
    Set MTA_BASE_URL and MTA_MODEL in .env, then hand the agent a task in plain language.
    
    
    
      
      
    
    
    
    
      
    

    

    $ uv run mta "Numerically solve the Lorenz system (sigma=10, rho=28, beta=8/3) from (1, 1, 1) over t in [0, 40] with scipy, and write the maximum value of z to /root/zmax.txt with 3 decimals." --image python:3.12-slim
    

    
      
    
      
    

    

    import asyncio
from mta import (Agent, DockerEnvironment, OpenAIModel,
                 TrajectoryRecorder, default_tools)
from mta.config import load_dotenv, model_config_from_env

TASK = ("Numerically solve the Lorenz system (sigma=10, rho=28, beta=8/3) from (1, 1, 1) "
        "over t in [0, 40] with scipy, and write the maximum value of z to /root/zmax.txt "
        "with 3 decimals.")

async def main():
    load_dotenv()
    model = OpenAIModel(model_config_from_env())
    async with DockerEnvironment(image="python:3.12-slim") as env:
        agent = Agent(model, env, default_tools(),
                      recorder=TrajectoryRecorder("runs/demo.json"))
        return await agent.run(TASK)

traj = asyncio.run(main())

    Reinforce
